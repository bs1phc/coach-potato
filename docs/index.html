Setup · about 3 minutes

Getting started

Coach Potato needs two things before it can show you anything: a Riot API key and the accounts you want to track. You set both in Settings (⚙, top-right), then run your first update.

  1. Get a Riot API key

    Open developer.riotgames.com and copy a key. A registered personal product key is persistent; the instant development key also works but expires every 24 hours.

  2. Paste it into Settings → Riot API & accounts

    Add the key, then add each account as Name#TAG (e.g. Faker#KR1). Pick your Server / platform. Stats combine all tracked accounts.

  3. Press Update data (⟳)

    The first crawl walks your full match history — roughly 2 minutes per 100 games. After that, updates are incremental and fast, and can run automatically on a schedule you choose.

  4. Explore

    Head to Overview for the big picture, or jump straight into a Matchup guide for a champion.

Heads up A development key stops working after 24 h — when crawls start failing with an auth error, paste a fresh key in Settings. All stats are scoped to top lane; every role's data is stored, so it's a display setting, not a re-crawl.

Tab

Overview

Your dashboard. A filter row across the top drives everything below it.

⚙
Filters
Period (7d / 30d / custom…), champion, queue, map side (blue/red), opponent rank, and minimum games. They apply across Overview, Matchups, Trends and Progress.
▦
Summary tiles
Win rate, KDA, CS/min, gold and damage at a glance for the current filter.
📈
Rank over time
Your solo-queue rank charted as ladder points. Real snapshots are solid; between them, faint estimated points are interpolated from ranked wins/losses. Coaching-session dates appear as vertical markers.
🏆
My champions
A per-champion table (expand it from the heading) — games, win rate and averages.
🎮
Recent games
Your latest games with a ▸ toggle per row that expands both players' rune pages side by side — yours and your lane opponent's.

Tab

Matchups

How you perform against each top-lane opponent. Two views:

By matchupGrouped by opponent rank

Every row is one enemy champion — games, win rate, KDA and CS. Expand a row for a win/loss timeline and any block notes you've written for that matchup. The 📖 link (shown when a specific "My champion" is selected) jumps straight to that matchup's guide.

🎛️
Metric columns
Add average columns for coaching metrics (lane Δ, CS@10, kill participation, vision…) via the column picker. They start hidden to keep the table clean.
🔵
Side filter
Restrict to games where you were on blue or red side.
⧉
Compare · ⏱ Cooldowns
Per-row buttons open the player comparison and the ability-cooldown tool for that matchup (see below).

Tab · the core of the app

Matchup guide

A living playbook for one of your champions. Pick My champion from the full roster (not just champions you've played), then build up notes, runes and item builds for every matchup it faces.

📝
General notes & item build
Champion-level Markdown notes and a mobafire-style item build (labelled sections you can drag to reorder) shown above the matchup list.
🔮
Per-matchup runes, patch & notes
Each matchup carries full rune pages (built with a click-through picker — keystone, minor rows, secondary, shards), a patch string, and Markdown notes on how to play it. A matchup can hold several rune pages (e.g. alternatives you're testing).
🎮
Recent games
The 20 most recent games in that matchup with the actual runes, spells and items you ran. A “+ guide” button saves a played rune page into the guide.
🔎
Search & sort
Filter the matchup list by opponent name; matchups you've written up sort to the top, then the rest — each group A→Z.
📄
One Pager
A full-screen, second-screen quick reference for a matchup: runes, skill order, items, notes — no stats. Press Esc to close.
⏱
Cooldown compare
Compare ability cooldowns between the two champions at any level, with haste sources and a skill-order grid. Save a build back to the matchup guide.
📡
Live Lookup
Finds your live game and opens the One Pager for the matchup automatically (guessing the lane opponent, which you can correct).
↕
Export / Import
Export a champion's whole guide as JSON (optionally password-encrypted) or a printable PDF; import someone else's.
Tip "My champion" comes from the full roster, so you can prep a guide for a champion before you've ever played it.

Inside the Matchup guide · ⧉

Player comparison

Add up to six other players (by Riot ID, in Settings → Research & comparison) and compare how they play a matchup against how you do. The ⧉ button on a guide row opens a side-by-side pop-out — great for a second screen.

🛡️
Does this player win lane?
A laning-phase block per player: how often they're ahead at 7 and 14 min, ΔCS / ΔGold vs the direct lane opponent, and CS@10 · solo kills · plates.
🎯
What they actually ran
Per recent game: summoner spells, the full rune page (with stat shards), the ability max order (Q›W›E), and the full build in purchase order. Toggle "Show spells & items" to reveal them.
🧩
Patch filter & layout
Filter each player's games to a specific patch. Cards are one wide by default and grow to a max of three per row.
How it fetches Comparison players are pulled on demand in the background (they can be on a different region than you). Their match data is stored like anyone's, but they stay out of your own tracked stats.

Tab

Coaching progress

Track improvement across coaching sessions — dated checkpoints you create as you learn something new.

  • Each session has a title and Markdown notes, and can hold video clips (uploads or pasted YouTube/Twitch links) for specific moments.
  • The progress table splits your stats into segments — a baseline, the periods between sessions, and since your last one — so you can see whether a metric moved after you worked on it.
  • Expand any segment to see the individual games behind it.

Export all sessions as one Markdown file from the section header.

Tab

Blocks

Structured practice. A block is a small set of games (default 3) played in one sitting, tied to a champion pool and your learnings.

♟️
Champion pool
Organise champions into main-blind / core / counter, in a priority order you set by dragging. Edited in Settings; shown read-only on the Blocks tab.
📦
Blocks & series
Games auto-advance into blocks; a big time gap between games auto-closes one. Group blocks into a series (e.g. a two-week challenge). Add games with the “+ Block” buttons on any game row.
🎬
Per-game notes & clips
Each game in a block gets its own notes and clips, plus deep stats (lane deltas, both players' runes) shown on expand.
📤
Export
Export blocks as Markdown or CSV, or copy a summary formatted for Discord.

Tab

Trends

Your metrics over time as small-multiple charts, bucketed by day, week or month, with a breakdown table below.

Pick which metrics to chart with the column picker, and filter by champion, queue or side. Good for spotting whether something you've been practising is actually trending up.

Tab · optional

Research

A study journal for other players' games — separate from your tracked accounts. Each entry has a player name, optional champion/opponent, one Markdown notes field (general + VOD notes together), and multiple screenshots.

Use it to take notes while watching high-elo VODs — write timestamps inline (e.g. 14:32 — bad rotation) as part of the notes.

Tab · optional

Macros

A flat list of freeform, collapsible sections for game-macro notes — wave management, rotations, tempo — not tied to any champion or matchup. New sections append at the bottom; each has a title and one Markdown field.

Note Research and Macros can be hidden from the nav in Settings if you don't use them.

Reference · ⚙

Settings

🔑
Riot API & accounts
Key, tracked accounts, server, and how often to auto-update while the app is open.
📦
Blocks
Block size, the time-gap that auto-closes a block, and whether to group blocks into series.
🎨
Appearance
A background picture, UI opacity (surfaces stay translucent but keep a readable floor so text never disappears over a busy background), an accent colour, and a date format.
👤
Privacy & views
Hide your own rank/LP from all views, choose per-matchup vs one general rune set, show/hide the Research & Macros tabs, and set a default champion for the guide.
💾
Backup & restore
Download a full backup (notes, guides, blocks, sessions, clips, screenshots) as a single .zip, and restore it onto a fresh install. Match/rank data isn't included — Riot can always re-supply it.
🗑️
Remove an account
Delete a tracked account and purge its crawled data, while keeping your blocks, sessions and notes. You can re-add and re-crawl later.

Reference · under the hood

Data & updating

Coach Potato reads the Riot API and stores everything in a local SQLite database. It's polite about rate limits and only fetches what's new.

  • Incremental crawl. Pressing ⟳ pages your recent match ids and fetches details only for games it hasn't seen. Interrupted crawls resume cleanly.
  • Coaching metrics & lane deltas. Per-game metrics (CS@10, kill participation, vision…) and lane ΔCS/Gold/Level at ~7 and ~14 min come from the match timeline.
  • Backfills. Older games can be topped up with data added in newer versions — spells & items, runes, or timeline stats — without a full re-crawl. Comparison players fill in region-correctly on their next fetch.
  • Opponent rank is each opponent's current solo rank (the API has no historical rank), refreshed on a 7-day cache.
Rate limits The app enforces Riot's request limits for you. A first full crawl of a large history takes a while — let it run; it's a one-time cost.

Reference

Tips & shortcuts

  • Everything that shows notes renders Markdown — headings, bold, bullets, inline code.
  • The 📋 "What's new" button lists recent features; entries newer than the latest release show a badge.
  • In the cooldown tool and comparison pop-out, Esc or ✕ closes overlays.
  • The comparison and cooldown windows are separate pop-outs — if you don't see a change, close and reopen them (they cache their own page).
  • Set a default champion in Settings so the Matchup guide, cooldown tool and comparison all open on your main.
