👋 Welcome to Coach Potato! Add your Riot API key and the accounts to track, save, then hit Update data to fetch your match history (a long first crawl — roughly 2 minutes per 100 games).

Riot API & accounts

Get one at developer.riotgames.com. A personal product key is persistent; the instant development key works too but expires every 24 h — paste a fresh one when crawls start failing.

Any number of Riot IDs, e.g. Player#EUW. Stats combine all of them.

While the app is open, new games are fetched on this schedule (0 = off). Data also updates on startup and whenever you press Update data.

Your roles

Stats default to your main + secondary role, so autofill games don't muddy your matchups. Each view has a Role filter — pick "All roles" there to include every game.

Blocks

Blocks auto-advance after this many games. Applies to current and future blocks; finished blocks keep their size.

If a game you add starts this many hours away from the block's latest game, the block closes and a new one starts. 0 turns this off.

A series gives blocks a shared title + per-series number and a "+ New series" button. Untick to number blocks continuously as "#1, #2, …".

Matchup guide

"Per matchup" keeps rune pages in each opponent's row. "General" shows a single champion-level rune set by the item build. Switching back restores per-matchup pages.

Player comparison & profiles

Add other players (via the Riot API) to compare against in a matchup — their runes, spells, items and laning show beside yours in the Matchup guide's ⧉ pop-out. Games are fetched in the background (Riot's API is slow, so it can take a few minutes).

Profiles

A profile is a saved focus you switch between from the top-bar dropdown — an optional role and/or champion the app pre-selects across the views. Use it however suits you: a lane, a champion pool, a smurf, a goal — both fields are optional.

Research players — grouped by the champion they're for

Pick which champion this player mains (blank = shown for every matchup) and their server — they can be on a different region than your accounts. The Matchup guide auto-loads the players for your selected "My champion".

Backup & restore

Export everything (.zip)

Every session, block learning, matchup guide, note, item build and Research entry — plus uploaded clips and screenshots — as one .zip. Excludes your API key/accounts and crawled match history (Riot can re-supply that).

Restore an "Export everything" .zip — only for a fresh/empty setup. Refuses (nothing written) if anything would collide with existing data.
